# Azure Study Path

A phase-by-phase Azure learning checklist, tailored to a C#/.NET, PostgreSQL, and Angular
stack — from first account setup to a certified, production-shaped deployment.

## Usage

Open `index.html` directly in a browser, or enable GitHub Pages for this repo
(Settings → Pages → deploy from the `main` branch) to view it as a hosted site.

Progress is tracked with checkboxes and saved in the page itself (no backend needed).

## Structure

14 phases, roughly in the order you'd actually learn them:

1. Prerequisites and Environment Setup
2. Core Cloud Concepts
3. Identity and Access — Microsoft Entra ID
4. Compute for .NET Workloads
5. Data Platform — PostgreSQL on Azure
6. Hosting the Angular Frontend
7. Networking and Private Connectivity
8. Security
9. CI/CD and Infrastructure as Code
10. Monitoring and Observability
11. Messaging and Integration
12. API Management and Architecture
13. Capstone — Ship One Real Thing End to End
14. Certification Path (AZ-900 → AZ-204 → optional AZ-400/AZ-305)

Phases tagged **Core focus** and items tagged **Deep dive** are the ones worth
studying beyond the surface for this stack.
