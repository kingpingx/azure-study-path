# Study Paths

**Live: [kingpingx.github.io/azure-study-path](https://kingpingx.github.io/azure-study-path/)**

Phase-by-phase learning checklists, tailored to a C#/.NET, PostgreSQL, and Angular stack.
One page, two tabs — each with its own progress.

## Usage

Open the [live page](https://kingpingx.github.io/azure-study-path/) and check items off as
you go, or open `index.html` directly in a browser to use it offline. Progress is saved per
tab in that browser's local storage.

Phases tagged **Core focus** and items tagged **Deep dive** are the ones worth studying
beyond the surface for this stack.

## Azure — 14 phases

From first account setup to a certified, production-shaped deployment.

1. Prerequisites and Environment Setup
2. Core Cloud Concepts
3. Identity and Access — Microsoft Entra ID
4. Compute for .NET Workloads
5. Data Platform — PostgreSQL on Azure
6. Hosting the Angular Frontend
7. Networking and Private Connectivity
8. Security
9. CI/CD and Infrastructure as Code
10. Monitoring and Observability
11. Messaging and Integration
12. API Management and Architecture
13. Capstone — Ship One Real Thing End to End
14. Certification Path (AZ-900 → AZ-204 → optional AZ-400/AZ-305)

## Java — 22 phases

From first `javac` to distributed, event-driven systems that scale.

1. Environment and Java Fundamentals
2. Collections, Generics and Streams
3. JVM, Build Tools and Logging
4. Spring Core and Spring Boot
5. REST APIs and Angular Integration
6. Persistence — JPA, Hibernate and Flyway
7. PostgreSQL Beyond CRUD
8. Spring Security, OAuth2 and JWT
9. Testing
10. Java Concurrency
11. Caching and Redis
12. Distributed Systems Fundamentals
13. Scaling Systems
14. Messaging — Kafka and RabbitMQ
15. Event-Driven Patterns
16. Microservices and Architecture
17. Resilience and Fault Tolerance
18. Docker, Kubernetes and Delivery
19. Observability
20. System Design Practice
21. Capstone — Event-Driven Analytics Platform
22. Reading and Certification Path

Phases 1–11 assume you know backend engineering already and cover only where Java differs
from .NET — the tab opens with a collapsible **.NET → Java map**. Phases 12–17 and 20 are
language-agnostic: distributed systems, scaling, event-driven patterns, and resilience.

## Notes

The repository name predates the Java tab. Both paths live in `index.html`, which is a
single self-contained file — no build step, no dependencies beyond a webfont.
